# Trader screen prompts — one file per screen

43 copy-able UI prompts for the **trader side** of Alpha One, extracted from the
specification in `alpha-one/docs/`. Each file holds exactly one screen's prompt
inside a fenced block — open the file, copy the block, paste it into your UI tool.

The full document (flows, screen index, global design brief and all prompts
together) is [`../trader-flows-and-screen-prompts.md`](../trader-flows-and-screen-prompts.md).
